Candidate information

The source of truth about this candidate — verified background, employers, dates, titles, technologies, prior resume text, real metrics. The resume prompt is told not to contradict it and not to claim anything it does not support.

Put {CANDIDATE_INFORMATION} in the resume prompt below to control exactly where this lands. Without that placeholder it is appended to the end of the prompt under its own heading.

Project manifest

Real projects you delivered in the roles on your resume. When a resume is generated, updated, or an answer is written, the projects that match the job description are picked automatically and used as the factual basis — the rest are left out.

One project per paragraph (blank line between them), or one per line as a - list. Put the employer, the stack, and the outcome in the text so the project stays attached to the right job, e.g. Uniqcli (2023) — Rebuilt order pipeline: Node.js, Kafka, Postgres; cut latency 40%.

Put {PROJECT_MANIFESTS} in the resume prompt below to control where the matched projects land. Without it they are appended to the end of the prompt with usage rules.
